# Font changes applied by tools\build.ps1 (via fontpatch.exe) to the game's font in USER.BIN.
# Each: a line "glyph <character> <normal|bold>", then exactly 12 rows of 16 pixels ('#' = ink, '.' = empty).
# Letters sit in rows 1-9 and start at column 1, like the rest of the font. The bold copy is the normal
# shape plus one extra pixel to the right (the game draws bold in black under white for the outline,
# and bold alone in dark text). Optional, unapplied fixes live in font-fixes-optional.txt.
#
# Squeezed "TCHI": two characters, [ = "TC" and ] = "HI", so a name ending takes 2 letter spaces like
# the Japanese っち did, instead of 4. In translations.tsv, write "[]" wherever a name ends in TCHI.
# [ and ] are never used by the game's own text.
